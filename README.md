# Análise de Dados: Supermercado Chileno

Este projeto foi desenvolvido como parte do curso de Cientista de Dados (Módulo 13). O objetivo é aplicar conceitos de estatística descritiva, tratamento de dados e visualização para entender o comportamento de preços e descontos de um supermercado.

## Tecnologias Utilizadas
* **Python** (Pandas, Matplotlib, Plotly)
* **Jupyter Notebook / PyCharm**

## Principais Insights
1. **Média vs Mediana:** Todas as categorias apresentaram média acima da mediana, indicando uma distribuição assimétrica à direita (puxada por produtos de alto valor).
2. **Outliers:** A categoria de Lácteos apresentou o maior desvio padrão, com forte presença de *outliers* (como packs de 12 unidades e leite em pó).
3. **Descontos:** As categorias de Lácteos e Congelados concentram as maiores médias de desconto em valores absolutos.

## Visualizações
* Gráfico de Barras - Média de Desconto por Categoria
* Boxplot - Distribuição de Preços em Lácteos
* Mapa Hierárquico - Descontos por Categoria e Marca
